# Fluir

💧 Sistema de Gerenciamento de Água
Um sistema desenvolvido em Flask para gerenciar e realizar pedidos de água para residências. O objetivo é facilitar o processo de solicitação, controle e entrega de água potável para clientes de forma simples e eficiente.

🚀 Funcionalidades
Cadastro de pedidos de água informando quantidade, endereço e contato.

🏠 Registro de clientes com dados básicos.

📋 Listagem de pedidos pendentes, em andamento e finalizados.

✅ Atualização do status dos pedidos (pendente, entregue, cancelado).

🔍 Busca de pedidos por cliente ou endereço.

🛠️ Tecnologias Utilizadas
Python

Flask (framework web)

HTML/CSS/Bootstrap para interface

SQLite (banco de dados leve)
